# Приложение для прогноза погоды

Веб-приложение для просмотра прогноза погоды с поддержкой геолокации и добавления городов.

## Функциональность

- ✅ Запрос геолокации при первом открытии
- ✅ Прогноз погоды на сегодня и минимум на 2 следующих дня
- ✅ Форма добавления города при отклонении геолокации
- ✅ Добавление дополнительных городов (минимум 2)
- ✅ Кнопка "Обновить" для повторной загрузки данных
- ✅ Сохранение состояния в localStorage
- ✅ Выпадающий список городов при вводе
- ✅ Валидация введенных городов
- ✅ Адаптивный дизайн для мобильных и десктопных устройств
- ✅ Состояния загрузки и ошибок

## Технологии

- HTML5
- CSS3 (чистый CSS, без фреймворков)
- JavaScript (ES6+, без фреймворков)
- OpenWeatherMap API

## Установка и настройка

1. Клонируйте репозиторий или скачайте файлы проекта

2. Получите API ключ от OpenWeatherMap:
   - Зарегистрируйтесь на [OpenWeatherMap](https://openweathermap.org/api)
   - Перейдите в раздел API Keys
   - Создайте бесплатный API ключ (Free tier)

3. Откройте файл `script.js` и замените `YOUR_API_KEY_HERE` на ваш API ключ:
   ```javascript
   const API_KEY = 'ваш_api_ключ_здесь';
   ```

4. Откройте `index.html` в браузере или используйте локальный сервер:
   ```bash
   # Используя Python
   python -m http.server 8000
   
   # Или используя Node.js (http-server)
   npx http-server
   ```

## Использование

1. При первом открытии приложение запросит доступ к геолокации
2. Если доступ разрешен - отобразится прогноз для текущего местоположения
3. Если доступ отклонен - появится форма для добавления города
4. Используйте кнопку "+ Добавить город" для добавления дополнительных городов
5. Используйте кнопку "Обновить" для обновления данных о погоде
6. Все данные сохраняются автоматически и восстанавливаются при перезагрузке страницы

## Особенности реализации

- Не используется `innerHTML` - все элементы создаются через DOM API
- Чистый JavaScript без фреймворков

- Обработка всех состояний: загрузка, успех, ошибка
- Валидация ввода городов
- Выпадающий список с автодополнением
